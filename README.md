# 家庭喜匯｜精神健康公開求助資源

聖雅各福群會 **家庭喜匯**（SJS Family Joy Connect）公開靜態網頁：只提供求助熱線與資源簡介，**不載個案、新聞或識別資料**。

## 內容

| 檔案 | 說明 |
|------|------|
| `index.html` | 首頁 |
| `hotlines.html` | 求助熱線一覽 |
| `about.html` | 關於家庭喜匯 |
| `disclaimer.html` | 免責聲明 |
| `styles.css` | 共用樣式（流動版友善） |

## 啟用 GitHub Pages

1. 將本目錄檔案推送到 repo `ycsoeric/hk-mh-public` 的預設分支（建議放在 repo **根目錄**）。
2. 於 GitHub：Settings → Pages → Source 選 **Deploy from a branch**。
3. Branch 選 `main`（或你的預設分支），資料夾選 `/ (root)`，儲存。
4. 稍候即可於 `https://ycsoeric.github.io/hk-mh-public/` 瀏覽。

無需建置步驟；純 HTML／CSS。
